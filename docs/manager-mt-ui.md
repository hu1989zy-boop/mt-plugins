# MT 风格管理界面（0.4.0，2026-09-16）

本次重做 `TradeCopierManager.exe` 的布局，采用 Windows 原生标签页、系统字体、白色内容区、灰白相间的表格行及紧凑按钮，参考 MT 插件属性窗口。它仍是独立管理程序。

## 新界面

| 位置 | 内容 |
| --- | --- |
| 常规 | 跟单配置启用、读取生效配置、关系列表；左侧添加 / 编辑 / 删除 |
| 关系弹窗 | 源账号、跟单账号、手数方式、参数、启用；确定写入草稿，取消放弃本次字段修改 |
| 配置文件菜单 | 新建、打开 JSON、保存到文件、另存为 |
| 运行状态 | 暂停 / 恢复新仓；以子标签切换“仓位映射”和“交易请求”，下方显示操作结果 |
| 信息 | 服务器 / 应用 ID、本机连接要求、初始配置及运行账本路径、账本版本、固定跟单规则 |
| 所有页面 | 顶部保留运行 / 暂停 / 停止 / 状态未知及数量；底部保留连接状态、连接 / 刷新、应用配置及关闭 |

- 默认窗口为 960 × 720、最小为 860 × 640 逻辑像素；跟随系统 DPI 缩放。尚不支持逐监视器 DPI 重排。
- 关系可双击或按 Enter 编辑。Ctrl+N / O / S 对应新建 / 打开 / 保存，Ctrl+Tab 切换主标签页；编辑弹窗支持 Tab、Enter 和 Escape。
- 常用账号、手数和状态列排在前面；完整关系 ID 保留在表格末列和编辑弹窗中。较宽的运行表格可横向滚动，列宽可拖动调整。
- 运行列表仍最多显示各 200 行；子标签显示“已显示 / 总数”。映射优先显示未结束项，交易请求显示最近项。
- 应用、暂停 / 恢复、只读核对返回后在运行页显示结果。读取生效配置返回常规页；主动连接失败也会展示运行页中的错误详情。
- 无变化的数据不重建运行表格；数据变化时保留所选请求和滚动位置。切换子标签不会丢失所选请求。

## 操作语义

**0.4.1 行为更新：** 新增订阅已支持带仓应用，原有持仓无需平仓；有持仓的原关系需保留设置。此功能需同步更新执行器及账本工具，见 [更新说明](config-with-open-positions.md)。本页下方的仅替换管理 EXE 步骤适用于之前的界面改版。

保存文件只保存本地草稿，底部“应用配置”才提交至执行器。0.4.1 应用前要求暂停、请求已确认且无待核对映射，并保留有持仓的原关系设置；确认框继续列出本次配置。应用后仍暂停，检查后在运行页恢复。

新增关系默认停用；修改账号组合会重新生成关系 ID 并停用，修改手数参数保留原关系 ID。编辑弹窗的取消不会写入草稿。

已包含 [后台刷新修复](manager-refresh-fix.md)：普通自动刷新不会占用用户操作状态；一次等待中的点击保留原请求 ID / 配置及版本，状态变化时拒绝发送。读取配置期间锁定草稿编辑，菜单和快捷键也遵守该限制。核对按钮在“交易请求”子标签选中一行后才可用。

## 更新现有 Demo 的管理 EXE

本更新兼容当前 0.4.0 管理协议，仅需替换管理 EXE。执行器 DLL、插件参数、配置及原 `executor-two-to-one.journal` 继续沿用。

1. 将 `mt5-trade-copier-0.4.0-mt-ui-source.zip` 解压，其中 `mt-plugins` 的内容合并到 `D:\work\mt-plugins`。
2. 打开 VS x64 Native Tools Command Prompt，在项目目录执行：

   ```cmd
   cd /d "D:\work\mt-plugins"
   scripts\build-windows.cmd -UiOnly -BuildDirectory build-windows-mt-ui
   ```

   此命令不需要 MetaTrader SDK。等待 `Build and tests passed`；Windows 管道测试需管理员权限，否则会被跳过。
3. 关闭旧管理界面并备份其 EXE。把新文件：

   ```text
   D:\work\mt-plugins\build-windows-mt-ui\package-ui\TradeCopierManager.exe
   ```

   复制到 `D:\MT5Copier\TradeCopierManager.exe`。
4. 以管理员身份启动新界面，在信息页核对服务器 ID `1`、应用 ID `3101`；点击底部“连接 / 刷新”，常规页“读取生效配置”。

## 验证情况

已完成：

- macOS 核心、配置、执行、管理客户端调度共四组 CTest 通过，启用 ASan / UBSan。
- Windows 管理 EXE 和调度测试 EXE 的 LLVM-MinGW 交叉编译通过。
- 客户端串行调度测试仍覆盖后台刷新期间接受一次点击、避免重发、固定配置 / 请求 ID、版本和会话检查以及读取配置期间草稿保护。

尚待 Windows 实机确认：

1. 100%、125%、150% 缩放下的标签页、表格与弹窗不遮挡，最小窗口可操作；Tab、Enter、Escape 与文件快捷键可用。
2. 读取现有配置后，50001 → 50002 比例 1、50003 → 50002 固定 0.02 及完整关系 ID 保留。编辑后取消不改变表格；确定才写入草稿。
3. 后台刷新时按钮不周期性闪灰，交易请求的选择和核对结果保持；选中一条请求后只读核对，其请求 ID、结果与旧界面一致。
4. 读取配置期间无法通过菜单、快捷键或弹窗修改草稿；运行页能看到现有映射、请求和暂停状态。
5. 关闭并重新打开界面不会改变执行器状态；连接失败时明确显示状态未知及上次快照。

交叉编译不等于 Windows 实机运行。此前 Demo 的业务流程验收记录仍见 [Windows 构建验证记录](windows-build-validation.md)，不将其计作本次新布局的视觉验收。
