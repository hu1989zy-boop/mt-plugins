> **Windows 构建更新**：0.4.6 已在用户本机测试发现检查点替换失败，改用 [0.4.7 修复包与构建步骤](../docs/windows-checkpoint-fix.md)；下文旧版本命令仅供历史参考。

0.4.6 支持同时在管 10,000 条映射，并同步扩大快照及文件容量保护；需一起更新执行器、界面和账本工具，详见 [10,000 条容量说明](../docs/ten-thousand-capacity.md)。

0.4.5 运行页仅保留在管及待核对记录，确认平仓后清理；信息页显示容量暂停原因。须一起更新执行器和账本工具，详见 [运行账本与容量保护](../docs/live-state-journal.md)。

0.4.3 的延迟调整在执行器，需一起更新 DLL 和工具；界面信息页显示 0.4.3。构建及 Demo 对比步骤见 [分账号调度](../docs/account-pipeline.md)。

`TradeCopierManager.exe` 采用 MT 属性窗口风格的三个原生标签页：

- **常规**：读取生效配置、关系列表和配置文件菜单。添加或双击关系，在独立弹窗中编辑。
- **运行状态**：暂停 / 恢复新仓、仓位映射、交易请求及只读核对结果；用子标签切换两张表。
- **信息**：服务器 / 应用 ID、配置与账本路径、账本版本和跟单规则。

顶部的执行状态和底部的连接状态始终可见。“保存到文件”只保存草稿；底部“应用配置”会确认内容，等待执行器提交成功后才生效。

管理模式需在 **MT5 Trade Server 同一台 Windows 电脑**以管理员身份运行，并在插件开启 Integer `ManagementEnabled=1`。默认服务器 ID `1`、应用 ID `3101`；关闭界面后执行器继续运行。

本次 0.4.2 带仓新增 / 修改订阅需同步更新执行器 DLL 和账本工具，见 [更新步骤](../docs/frozen-opening-rules.md)。此前界面布局更新步骤见 [MT 界面更新说明](../docs/manager-mt-ui.md)。完整管理协议、配置来源及 Demo 流程见 [管理界面说明](../docs/management-ui.md)。构建出的 `package-ui` 目录也附带这两份说明。

## 编译管理 EXE

在 VS 2022/2026 x64 Native Tools Command Prompt 中、项目根目录执行：

```cmd
scripts\build-windows.cmd -UiOnly -BuildDirectory build-windows-mt-ui
```

管理 EXE 自身不依赖 MetaTrader SDK，可连接 0.4.0 管理通道；带仓新增 / 修改订阅需要执行器升级到 0.4.2。MSVC 使用静态 `/MT` 运行库。产物位于 `build-windows-mt-ui\package-ui`。

## 配置编辑

1. 常规页“配置文件”菜单新建 / 打开 JSON，或连接后“读取生效配置”。
2. 添加关系，填写账号、手数方式和参数，按需勾选启用，点击“确定”写入草稿。取消 / Escape 放弃本次字段修改。
3. 双击或选中后按 Enter 编辑。参数校验、自跟单 / 重复关系 / 循环检查和完整 64 位 ID 均保留。
4. 改变账号组合会生成新关系 ID 并停用；仅改手数参数保留 ID。
5. “配置文件 → 保存到文件 / 另存为”只写 UTF-8 JSON。Ctrl+N / O / S 对应新建 / 打开 / 保存。
6. 在运行页暂停新仓，等待正在提交的请求确认后可“应用配置”。已有持仓无需平仓；老仓保留开仓规则，新仓使用新配置。成功后仍暂停，检查后恢复。

新建配置和关系默认停用。只跟恢复后的新源仓，不补跟旧仓；不复制挂单及 SL/TP 数值，跟随源实际平仓；手动全平后停止该映射。Close By 不在本版范围。

## 刷新与显示

正常后台刷新不会让按钮周期性闪灰；点击遇到在途刷新时会暂存一次，返回后检查状态再提交。读取配置期间锁定草稿编辑；超时或执行器会话 / 账本版本变化时不会自动重发写命令。

窗口跟随系统 DPI，默认 960 × 720、最小 860 × 640 逻辑像素，表格可横向滚动和调整列宽。尚未实现逐监视器 DPI 重排。运行列表只展示本跟单器记录，不代表账户全部持仓。

连接失败或快照超过 6 秒未更新时禁用执行操作。HALTED、REVIEW、未决请求和操作结果仍可查看；“交易请求”中选中一行后可只读核对，不能用它解除停止或重发交易。Windows 上的 MSVC 构建和本次新布局交互、DPI 显示仍待实机验证。
