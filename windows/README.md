# Windows 本地配置管理界面

`TradeCopierManager.exe` 是原生 Win32 桌面程序，用于编辑和检查 MT5 跟单配置 JSON。它不是运行监控台，不连接 MT5，不读取账户或净值，不向服务器发送配置，也不会下单。窗口中的“启用”仅是待导出的配置值，不代表服务器实际启用。

## 在 Windows 上编译

在源码项目根目录，安装 Visual Studio 的“使用 C++ 的桌面开发”、Windows SDK 和 CMake 组件。推荐在 VS 2022/2026 的 **x64 Native Tools Command Prompt** 执行 `scripts\build-windows.cmd -UiOnly`；VS2026 需要 CMake 4.2+。下面是使用 VS2022 的直接 CMake 命令示例：

```powershell
cmake -S . -B build-windows -G "Visual Studio 17 2022" -A x64
cmake --build build-windows --config Release --target TradeCopierManager
.\build-windows\windows\Release\TradeCopierManager.exe
```

配置管理程序不依赖 MetaTrader SDK。若项目根 CMake 另外提供构建开关，请以根目录部署说明为准。运行库由根工程统一配置：默认使用 MSVC 静态 `/MT`，无需另装 Visual C++ 运行库；若改为 `/MD`，运行电脑需要对应的 Microsoft Visual C++ x64 运行库。该目录由根 CMake 的 Windows 分支引入，不能把此目录单独作为 CMake 项目构建。

用户回传的 VS2026 构建截图已确认生成本 EXE，两组核心/配置测试通过。界面启动与操作尚未验证，不能把下面的验收清单视为已通过；见 [构建记录](../docs/windows-build-validation.md)。

界面按启动时的 Windows 系统 DPI 缩放，支持调整窗口大小；建议工作区至少为 1060 × 690 逻辑像素（例如 150% 缩放时约需 1590 × 1035 物理像素）。更改系统显示缩放后请重启编辑器；不同 DPI 显示器之间移动窗口时依赖 Windows 缩放。本版未实现跨显示器逐监视器 DPI 布局。

## 使用

1. 打开项目的 `config/copier.example.json`，或“新建文件”从空配置开始。
2. 点击“新增关系”，填写信号源、跟单账号，选择手数比例、净值比例或固定手数并填写参数。账号和关系 ID 均保留完整的 64 位整数，不经过浮点转换。
3. 点击“更新 / 加入列表”提交编辑到本地列表。每个源账号与跟单账号组合只能出现一次；不允许自己跟自己或循环跟单，停用的关系也参加检查。
4. 选择已有行可编辑参数或删除关系。改变源账号或跟单账号时，将生成新关系 ID，并强制把该关系设为停用。仅改变手数模式或参数会保留 ID。
5. “保存”或“另存为”写出 UTF-8 JSON。保存前会检查整份配置；文件通过同目录临时文件再替换写入，失败时保留原文件。尚未提交的表单会提示先更新关系，确认后通过校验才继续保存，不会被悄悄省略。
6. 切换关系、新建、打开文件及退出时，未提交的编辑或未保存内容会提示处理。可以选择保存、放弃或取消。

文件固定策略为：同服 MT5、USD、Hedging、多对多；只跟启用后的新持仓；不复制挂单或 SL/TP；全手动平仓后停止跟随该映射；源部分平仓按比例减少实际跟单剩余持仓。界面不提供改变这些策略的开关。

净值比例的取值策略为：收到源开仓成交后，在提交跟单前查询源账户和跟单账户各自的当前 USD 净值，并冻结用于本次计算。执行层需要分别记录源成交时间与净值查询时间，不应将查询结果表述为源成交瞬间的历史净值。本编辑器仅保存此策略，不自行查询账户。

## Windows 验收清单（待执行）

- 打开中文路径中的有效 JSON，新增多个源和多个目标，检查三种模式和公式提示。
- 尝试重复组合、自跟单、循环、零参数、错误 JSON 及超限文件，确认报错且现有配置不丢失。
- 修改源/目标，确认产生新 ID 且停用；仅修改参数时 ID 不变。
- 使用超过 `2^53` 的账号/ID，保存后重新打开，确认十进制文本逐位一致。
- 在表单尚未加入列表时尝试保存、换行、打开文件和退出，确认提示有效。
- 通过中文路径另存，修改后再次保存；在无写权限位置保存时确认错误可见且原文件完整。
- 缩放 Windows 显示、调整窗口、键盘 Tab 导航，确认中文、列表与表单可读。
- 验证“启用”只能修改草稿，程序没有服务器连接或交易操作入口。

SDK 插件的构建、安装与测试属于根目录部署说明，不能通过运行此 EXE 自动完成。导出的配置只有经过已实现的服务端接入步骤才可能生效。
