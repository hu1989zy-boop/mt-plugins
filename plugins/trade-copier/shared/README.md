# 跟单公共业务核心

`core/` 保存 MT4 / MT5 共用的手数算法、订阅配置、执行状态机、冻结开仓规则、账本及管理协议。`tests/` 保存公共核心、配置和未提交拒绝的回归测试；具体 SDK、订单查询和成交证明由各平台适配器负责。

`cmake/Core.cmake` 的 `tradecopier_add_core` 为每个平台分别编译静态库，通过 `TRADECOPIER_PLATFORM_NAME` 限定配置平台与原生拒绝码。MT5 继续使用 `tradecopier_*` 目标，MT4 使用 `mt4_tradecopier_*`；不同平台的库不可同时链接到同一执行器中。

数量统一为每手 100,000,000 个整数单位；MT4 在适配器中与 SDK 每手 100 个 volume 单位做精确转换，不允许无法表示的数量。执行器通过各自账本身份区分平台、服务器和实例，不共用运行账本。

本目录不提供跨服务器传输或 MT4 / MT5 互跟路由。后续路由协议还需为账号、订单及来源链加入平台和服务器身份，防止不同服务器上的相同数字编号发生碰撞。
